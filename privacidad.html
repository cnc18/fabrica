Política de privacidad

Última actualización: 23 de noviembre de 2026

«Fábrica de shorts» es una herramienta privada. La usa solo su propietario para gestionar sus propios canales de YouTube. No ofrece servicio a terceros.

Qué datos usa

Con la autorización expresa del propietario, la herramienta usa los Servicios de API de YouTube para:

  • leer el nombre y el identificador del canal autorizado;
  • subir y programar vídeos en ese canal;
  • leer estadísticas de esos vídeos: vistas, me gusta, comentarios, tiempo de visualización y suscriptores ganados.

Dónde se guardan

Los permisos de acceso y las estadísticas se guardan solo en el ordenador del propietario. No se envían a servidores propios ni de terceros. No se venden, no se comparten y no se usan para publicidad.

Uso de los datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

YouTube

Esta herramienta usa los Servicios de API de YouTube. Al usarla se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde la página de seguridad de la cuenta de Google: myaccount.google.com/permissions. Al revocarlo, se borran los permisos guardados en local.
